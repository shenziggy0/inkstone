# 设计文档：编号列表点击跳动修复

- 日期：2026-11-24
- 状态：已在工作树实现

## 1. 需求理解

点击编号列表的正文时，用户希望光标落在点击的字上，前后各项保持原位。旧 Mac 预览包中，一份 12 项的列表在点击第 2 项后，第 1 项正文从 130.8 移到 138 CSS 像素。第 6 项刚好接近行尾，多折了一行，第 10 项随之下移 25.6 像素。此时滚动位置始终为 0。

同一列表在阅读态使用 HTML 的 `ol` 和 `li`，在编辑态使用 CodeMirror 行和编号组件。原有两套样式分别为正文预留 1.8em 和 2.25em，差值随字号放大。光标进入编号本身时，还会触发 Markdown 前缀显露。

## 2. 接口改动

无对外接口改动。沿用现有块选择、光标映射和前缀显露逻辑。渲染层给显露的有序编号加上 `cm-ordered-source` 样式类，使可编辑的原始字符也能使用同一编号栏。[前缀装饰](../../src/editor.js)

## 3. 数据库改动

无。编号和正文继续保存在用户的 Markdown 文件中。

## 4. 流程图

```mermaid
flowchart LR
    read["阅读列表"] -->|"点击正文"| edit["编辑列表"]
    edit -->|"光标进入编号"| prefix["编辑原始编号"]
    prefix -->|"光标回到正文"| edit
    edit -->|"离开列表"| read
    read --> align["正文及折行共用起点"]
    edit --> align
    prefix --> align
```

## 5. 范围边界

本次处理录屏中的普通有序列表，以及其中一位数和多位数编号。引用、任务框、嵌套层级的排版和显式源码模式沿用各自的规则。

## 6. 验收标准

- [ ] 在桌面窗口打开 12 项真实 Markdown 列表，第 6 项包含接近换行边界的文字。
- [ ] 分别点击第 2 项、第 10 项，进入编号，再点标题离开列表。各项的可见行数与阅读态一致，每行正文起点、高度方向的位置和文本宽度与初始值相差至多 1 CSS 像素，滚动位置相同。
- [ ] 单纯点击时文档保持已保存。进入第 10 项编号插入数字后保存，磁盘文件仅出现预期的编号改动。[桌面回归用例](../../test/ordered-list-layout.desktop.mjs)

## 7. 影响面

在 `src/styles.css` 中以阅读态的列表缩进和条目内边距为基准。编辑行的左内边距取两者之和，首行悬挂缩进抵消同样的宽度，编号组件占据这段空间。这样，第一行正文和自动折行的正文从同一列开始。默认字号 16px 时，这一列距离正文栏左边缘约 28.8px。[排版样式](../../src/styles.css)

## 8. 回滚方案

若出现编号不可编辑、光标定位错误或其他列表回归，一并回退共享缩进样式与显露编号的样式类，重新构建并用同一份列表验证阅读、输入和保存。回退无需转换文档或用户设置。
