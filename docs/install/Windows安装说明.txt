Inkstone（墨页）Windows 安装与更新说明
=================================

1. 运行安装程序（Inkstone Setup）。
2. 若出现 Windows SmartScreen“Windows 已保护你的电脑”，点“更多信息”，再点“仍要运行”。
3. 按提示选择安装目录。把新版本装到旧版本所在的目录会就地升级，不必先卸载。
4. 把 Inkstone 设为 .md 的默认应用：打开“设置 → 应用 → 默认应用”，或右键 .md 文件 →“打开方式”→ 选择 Inkstone 并设为默认。

Windows installation (English)
------------------------------
Run the setup program. If SmartScreen appears (“Windows protected your PC”),
choose More info, then Run anyway.
Choose an installation folder. Installing a newer version over the old one
upgrades in place; you do not need to uninstall first.
To open .md files with Inkstone, use Settings → Apps → Default apps, or
right-click a .md file → Open with → Inkstone, and set it as the default.
