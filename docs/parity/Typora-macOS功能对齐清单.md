## 第一个已修复的差距：重复标题链接

普通三个同名标题在墨页中使用与参考版本相同的主 ID：`标题`、`标题-2`、`标题-3`。大纲、文内目录、编辑器的文内及跨文件跳转、增量渲染和 HTML 导出共享主 ID。墨页也计算旧编号；尚未被任何主 ID 占用的旧编号保留为兼容入口。例如旧 `#标题-1` 仍能跳到第二个标题。

**有歧义时以主 ID 为准。** 三个同名标题中，旧墨页的 `#标题-2` 原指第三项，Typora 的同一片段指第二项。需要指第三项的旧链接应改为 `#标题-3`。编辑器不会自动改写磁盘文稿。若另有字面标题“标题-1”，该标题的主 ID 优先于历史别名。

参考应用还实测了字面数字后缀在重复标题之前和之后的情形。例如 `# 固定-2`、`# 固定`、`# 固定` 会导出两个 `固定-2`。墨页按文档顺序避免重复主 ID，此例为 `固定-2`、`固定`、`固定-3`。这是有意保留的差异。该修复只覆盖编号分配，标点、格式化标题与所有 Unicode 字符的 slug 生成仍需专门对照。

## 其余验收顺序

1. **写作手感**：对两端输入相同的鼠标点击、拖选、组合输入与键盘序列，优先覆盖嵌套列表、跨块选择、表格与真实中文输入法。墨页的单端回归不能替代这一项。
2. **语法与文档输出**：按上述偏好分别启停可选语法，比较可见文字、DOM 语义及生成文件，字数以同一份原稿分别测量。
3. **缺失入口与平台集成**：独立跟踪只读、图片批量操作、额外导出格式、快捷键和 Windows/Linux 实机差异。此前仓库 82 项的复测结果继续作为回归依据。[上一轮双端复测报告](../evidence/2026-11-24-Typora全项目功能复测.md)
